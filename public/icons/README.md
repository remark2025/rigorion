# PWA Icons

Add the following icon files to this directory:

- `icon-192.png` - 192x192px icon for PWA
- `icon-512.png` - 512x512px icon for PWA

These should be your app's logo in PNG format with transparent background.

You can generate these from a high-resolution logo using:
- Online tools like https://app-manifest.firebaseapp.com/
- Design tools like Figma, Sketch, or Canva
- Command line tools like ImageMagick

Example sizes needed:
- 192x192 (required for PWA)
- 512x512 (required for PWA)
- 16x16, 32x32 (favicon)
- 180x180 (Apple touch icon)

# Interactive Math Solution Dependencies

Run these commands to install the required packages:

```bash
npm install plotly.js-dist-min react-plotly.js
npm install react-mathjax3 
npm install framer-motion
npm install react-dnd react-dnd-html5-backend
npm install zustand
npm install @types/plotly.js
```

## Libraries Used:
- **plotly.js**: Interactive graphs and visualizations
- **react-mathjax3**: Math expression rendering
- **framer-motion**: Smooth animations
- **react-dnd**: Drag and drop functionality
- **zustand**: State management
